# Illumine tes sens – Premium Wellness Website

A modern, premium spa & wellness website built with pure HTML, CSS, and JavaScript.

## Pages & Sections

- **Accueil (Home)** – Hero with full-screen spa imagery, tagline, and "Book your moment" CTA
- **Soins (Services)** – 6 cards covering massages, energy treatments, and rituals
- **À propos (About)** – Story, values, and human connection
- **Réservation (Booking)** – Full reservation form with validation
- **Contact** – Contact form, info blocks, and embedded map

## Design

- Warm beige, sage green, and gold color palette
- Cormorant Garamond serif headings + Poppins sans-serif body
- Smooth AOS scroll animations
- Rounded buttons, soft shadows, generous white space
- Fully responsive (desktop, tablet, mobile)

## Files

```
index.html        – Single-page app with all sections
css/style.css     – All styles (variables, layout, components)
js/main.js        – Animations, nav, forms, parallax
```

## Usage

Open `index.html` in any modern browser – no build step required.
